# 📐 Triangle Area Calculator - Heron's Formula

A Python program to calculate the area of a triangle using Heron's formula.

## 📖 Formula Used
`s = (a+b+c)/2`  
`Area = √[s(s-a)(s-b)(s-c)]`

The program first checks if the triangle is valid:
`a+b>c and a+c>b and b+c>a`
